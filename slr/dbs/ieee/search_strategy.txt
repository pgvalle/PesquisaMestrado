IEEE Xplore

Advanced Search

Reference help section:

Why All Metadata:
-----------------
IEEE Xplore exposes individual searchable fields such as Document Title, Abstract, Index Terms, and Author Keywords, but the structured Advanced Search interface does not provide a single simple field equivalent to Scopus TITLE-ABS-KEY.

All Metadata is therefore a practical approximation for the structured Advanced Search interface.

Important comparability note:
-----------------------------
All Metadata is broader than Scopus TITLE-ABS-KEY. In addition to title, abstract, and index/keyword information, metadata search can include other bibliographic metadata.

Consequences:
-------------
- The IEEE Xplore search may retrieve somewhat broader results than the Scopus TITLE-ABS-KEY search.
- This difference should be documented in the systematic-review methodology.

Strict-equivalence alternative:
-------------------------------
If strict title + abstract + keyword-like field control is required, IEEE Xplore Command Search is preferable because it supports free-form field expressions and nested Boolean concepts. The structured Advanced Search approach above is the simpler practical version.
